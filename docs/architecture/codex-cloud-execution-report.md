A candidata official-worker troca sua etapa documental. Consumidores da raiz, variantes de atletas, /app/ e push devem ser reconciliados primeiro. [Mapa de dependências e corte](legacy-import-retirement-plan.md).
6. **Recomendação.** Solicitar à STB autorização e um pacote LENEX do mesmo evento com balizamento, resultado e retificação. Fazer a prova descartável antes de codificar o adaptador esportivo de produção. Em paralelo, confirmar a oferta de API para entidades. Só trocar leitores e escritores quando a equivalência estiver demonstrada.

## Evidência executada

- `git ls-remote`, `git log --all`, `git show` e `rg` localizaram a missão fora da main e permitiram confrontar as árvores e dependências. Foram usados os dois planos de arquitetura, a revisão adversarial, a avaliação independente, as correções e relatórios de runtime, catálogo, recuperação e entrega não concluída. O histórico de outubro orienta os gates, sem representar estado de novembro.
- `curl -sSL --max-time 15` nos URLs públicos listados no [manifesto de evidência](evidence/2026-11-07-official-source-probes.json) e `sha256sum` dos corpos. Os hashes dos HTMLs da raiz e de /app/ coincidem com `git show origin/main:index.html` e `git show origin/main:app/index.html`. O bundle rastreado na main contém monitor-runner e request_result_refresh_v2. A igualdade foi medida para os HTMLs. Nenhuma chamada aos importadores foi feita.
- HTTP 200 para documentação, termos, política, evento amostrado e API editorial Masters. HTTP 403 para os dois portais federativos e 503 para a amostra histórica SwimSystem, nos caminhos observados. Isso registra a resposta nesta execução. A análise de âncoras considerou hrefs públicos e sua extensão, sem adivinhar endpoints internos. O [manifesto](evidence/2026-11-07-official-source-probes.json) preserva URL, status, tamanho, hash e contagens. Os corpos que podem conter nomes e registros de atletas não foram republicados no repositório público.
- A consulta somente leitura ao catálogo Supabase do projeto VINISWIM falhou pelo conector. O catálogo de produção, fontes personalizadas, crons ativos e deploys Railway/Edge atuais não foram revalidados. O inventário distingue evidência versionada de estado operacional.
- Node v24.22.1. `node --test prototypes/official-provider-contract/contract.test.mjs`: **5/5** contratos sintéticos. `(cd commercial/packages/import-v2 && npm test)`: **87/87** regressões. A execução adicional de `tests/*.test.mjs` nesse pacote passou 3/3. A leitura REST pública e a comparação com a página Masters comprovam somente o catálogo editorial. Identificação de atleta, importação, confronto de marcas, idempotência e correções reais continuam sem prova para a nova integração.

**Decisão por fonte.** SwimSystem e FDAP via SwimSystem: **VIÁVEL CONDICIONAL**. FGDA: **NÃO COMPROVADO**. Masters Paraná: **VIÁVEL** para metadados editoriais e **NÃO COMPROVADO** para dados esportivos sem processamento de documentos.

A entrega desta branch compreende documentação, evidência das consultas e o contrato local. Nenhuma mudança em produção, implantação, merge, alteração de frontend, desligamento ou exclusão de dados foi executada. A homologação operacional do VINISWIM segue pendente.
